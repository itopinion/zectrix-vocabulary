# 发布说明

在 Apple Silicon Mac 执行 `./scripts/package-app.sh`，得到 `dist/zectrix-vocabulary-版本-macos-aarch64.zip` 和 SHA-256。

应用包根目录包含 `app.json`、`bin/`、`workers/`、`assets/` 及说明和许可文件。所有文件哈希由脚本生成，不能手工保留旧哈希后替换二进制。新版本同步修改 `Cargo.toml` 与 `app.json` 的版本号。

语音依赖由 Hub 按需安装，应用包不包含 Python 运行环境或模型。演示数据必须是可分发、明确标注的示例；个人词库、教材整表、学习记录和真实录音不得进入发行包。

更新前备份，更新后验证原有词库与进度保留。实机测试至少包含：按键、录音、正确/错误拼写反馈、朗读未确认、音标显示、Kokoro 回放、音量与应用切换。转写正确不能作为准确声学评分的证据。

CI 模板保存在 `docs/github-actions/`，当前授权不含工作流权限，暂未启用；启用后只构建与上传候选产物，不自动公开发布。平台标识 `macos-aarch64` 只覆盖 Apple Silicon Mac；不要把此应用包标为群晖或 Windows 兼容。

设备要求 Note 4 官方固件 **3.7.0 及以上（≥3.7.0）**。升级请参考 [官方固件说明](https://wiki.zectrix.com/zh/software/firmware) 的 Note 4 部分。本应用不包含固件镜像或刷写操作。

## 生成源码归档

在本项目独立 Git 仓库中检查并暂存要发布的源码，执行 `python3 scripts/package-source.py`。脚本只归档 `git ls-files` 中的文件，拒绝数据、模型、固件、缓存和符号链接，不包含 `dist/`，不创建远端或公开发布。
