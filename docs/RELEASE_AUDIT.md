# 本地发布审计记录

检查日期：2026-10-14。此记录覆盖独立背单词项目源码及当时的 `0.2.0` macOS Apple Silicon 候选应用包，不表示已公开发布。

- Cargo.toml、Cargo.lock、app.json 版本一致；`cargo metadata --locked --offline` 通过。
- 无相邻工程路径依赖；设备通信和渲染通过运行中的 Hub 接口完成。
- 源码定向扫描未发现个人用户名、主目录、真实设备地址或旧实验环境的硬编码路径。
- ZIP 完整性和外部 SHA-256 通过，manifest 的每个文件哈希均吻合，包内没有额外条目。
- 不含个人词库、学习记录、真实录音、模型权重、固件或未授权 zfull 字体。
- 候选二进制仅保留依赖库错误定位使用的临时编译目录字符串，不含个人主目录和用户名，也不依赖该目录运行。
- GitHub Actions 模板已检查，因当前上传授权不含工作流权限，保存在 `docs/github-actions/`，尚未启用或执行远端 CI。

12 个单元测试、1 个模拟 Hub 流程测试，以及本轮 fullcanvas 实机验证的结果见 `RELEASE.md`。实机验证包括既有真实录音回放、画面和音频、应用切换；正式安装后另外完成 camp 真人设备拼写与朗读，两项来源均为 device，示范播放完成且使用者已确认。首次联网安装语音环境也未用已有环境复用的成功替代。

正式用户目录中的 Hub 已在 macOS 允许本地网络访问后，通过后台服务成功连接真实设备，并安装新版应用。语音模型就绪，迁移后词库、练习历史和音量设置比对一致；旧版服务已停止，原源码与数据保留用于回滚。

最终源码归档从 `git ls-files` 生成，不包含未跟踪文件和 dist。文档、脚本或运行文件修改后应重新打包并复核哈希。
